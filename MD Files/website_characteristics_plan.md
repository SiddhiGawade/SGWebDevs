# Website Characteristics Plan

This document serves as the single source of truth for the visual identity and technical implementation of the Rare Elephant Media website.

## 🎨 Design Infographics & System

### Color Palette
| Name | Hex Code | Tailwind Name | Usage |
| :--- | :--- | :--- | :--- |
| **Electric Yellow** | `#FFF200` | `brand-yellow` | Primary backgrounds, buttons, highlights |
| **Pitch Black** | `#000000` | `black` | Backgrounds (Timeline, Services), Text |
| **Pure White** | `#FFFFFF` | `white` | Text on black backgrounds, cards |

### Typography
| Role | Font Family | Usage |
| :--- | :--- | :--- |
| **Primary Headings** | **Oswald** | Main titles, impactful headers (Condensed, Bold) |
| **Body / Standard** | **Times New Roman** | Standard paragraphs, formal text sections |
| **Creative / Accents** | **Permanent Marker** | "Founder's Note", scribbles, handwritten annotations |

### Tech Stack
-   **Framework**: **React** (Vite)
-   **Styling**: **Tailwind CSS**
    -   *Reason*: Rapid UI development, easier animation integration, consistency.
-   **Animations**: **Framer Motion** & **Tailwind Animate**
    -   *Framer Motion*: Complex scroll-linked animations (Snake timeline).
    -   *Tailwind Animate*: Standard fade-ins, hovers, and transitions.
