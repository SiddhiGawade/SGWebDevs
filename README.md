# Rare Elephant Media (SPWebDevs)

A modern, high-performance marketing agency website built with React and Tailwind CSS. This project features a unique, visually striking design with smooth animations and interactive elements.

## 🚀 Features

-   **Hero Section**: Dynamic entrance with a bold visual hierarchy.
-   **Timeline ("The Story So Far")**: A custom-built SVG "mountain trail" path replica that visualizes the agency's journey with precision alignment.
-   **Services & Process**: Detailed sections explaining the workflow (`Process.jsx`) with connected visual elements (School bus road theme).
-   **Team**: Interactive team roster with hover effects and "hand-drawn" aesthetic elements.
-   **CTA**: A bold, wave-shaped call-to-action section at the bottom to drive conversions.
-   **Responsive Design**: fully adapted for both Desktop and Mobile experiences.

## 🛠️ Tech Stack

-   **Framework**: [React](https://react.dev/) (Vite)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **Animations**: custom CSS & SVGs (previously Framer Motion, optimized to static SVG paths for specific sections).

## 📦 Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/SiddhiGawade/SPWebDevs.git
    cd SPWebDevs
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

## 🚀 Deployment

This project is configured for deployment on **Vercel**.

1.  Push your code to GitHub.
2.  Import the project into Vercel.
3.  Vercel will automatically detect the Vite settings (`npm run build`).
4.  Deploy!

## 📂 Project Structure

-   `src/components/`: Contains all individual section components (Hero, Timeline, CTA, etc.).
-   `src/assets/`: Images and static resources.
-   `src/App.jsx`: Main entry point assembling the sections.
